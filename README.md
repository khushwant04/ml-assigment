# ML Assignment

This repository contains a set of machine learning exercises implemented in Jupyter notebooks. Each exercise focuses on a different regression or classification technique, using a small dataset bundled with the corresponding notebook.

## Project Structure

- [exercise_1/](exercise_1/) - Simple Linear Regression on Salary data
- [exercise_2/](exercise_2/) - Multiple Linear Regression on startup data
- [exercise_3/](exercise_3/) - AdaBoost regression for insurance charges prediction
- [exercise_4/](exercise_4/) - Random Forest classification for insurance-related data
- [exercise_5/](exercise_5/) - Support Vector Machine classification for social network ads

## Files Included

- Jupyter notebooks for each exercise
- CSV datasets used by the exercises
- Serialized trained models for selected exercises

## How to Use

Open any notebook in Jupyter Notebook or VS Code and run the cells in order. The datasets are already included in the repository, so no additional download is required.
